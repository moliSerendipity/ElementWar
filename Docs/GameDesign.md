# ElementWar 游戏设计总览

- 状态：已确认设计检查点
- 维护日期：2026-08-07
- 首发平台：Windows 64-bit
- 公开试玩目标：2026-09-10

本文只维护产品方向、首版范围和细则导航。它描述已经确认的目标设计，不证明对应功能已经实现；当前代码主线、旧架构和已知越界点以 [`Architecture.md`](Architecture.md) 为准，单项功能的实现与验证以对应 Feature Spec 和证据为准。

## 产品定位

- 中文名：元素战争；项目名：ElementWar。
- 类型：节奏紧凑的第三人称射击游戏。
- 核心灵感来自 HoYoFair 的《原神》二创内容，并把元素反应改造成适合射击玩法的战斗系统。
- 当前工程已包含 Tactical Lumine（荧）模型，首版计划从模之屋选择并导入茜特菈莉模型；后者尚未进入工程，具体页面、作者和授权条款也尚未登记。角色选定不代表授权确认，公开展示、可执行文件分发和源代码公开必须分别核验每项资产的来源、授权范围和再分发限制。
- 首版用于秋招作品集和公开试玩：计划发布 B 站展示视频，并通过网盘提供 Windows 可执行文件；是否公开源代码尚未决定。
- 首版正式支持键盘和鼠标，手柄适配不属于截止日期内的必做范围。

## 核心体验

1. 玩家使用步枪、榴弹枪和投掷物进行第三人称射击。
2. 枪械装填限定种类的元素弹药，命中后附着元素并产生两两反应。
3. 玩家在两名角色间切换；非主控角色由 AI 跟随和射击，技能仍由玩家主动切换后释放。
4. 一局由教学波、混合精英波和 Boss 波组成，前两波结束后各进行一次三选一强化。
5. 首版优先保证一段短而完整、可录制、可重复游玩的战斗体验，并为后续第三名角色、更多元素、枪械获取改装和网络实验保留扩展位置。

## 首版范围

| 领域 | 首版内容 |
|---|---|
| 队伍 | 两名角色：荧（火属性输出）、茜特菈莉（冰属性辅助）；未来最多扩展到三名角色 |
| 武器 | 步枪、榴弹枪、可弹跳的手雷；固定初始配装 |
| 元素 | 火、水、雷、冰，以及六种两两反应 |
| 敌人 | 近战追击者、远程射手、重型精英、两阶段 Boss |
| 流程 | 短入口/教学区、一个主竞技场、三波战斗、两次三选一 |
| 肉鸽 | 九个唯一且不可叠层的团队强化；无稀有度、商店、货币、重抽和局外成长 |
| 模式 | 正式试玩版为单机；联网只作为单机垂直切片之后的独立实验 |
| 叙事 | 一句话背景，不制作 NPC、对话、过场或大型剧情 |

## 首版非目标

- 完整复刻《原神》的元素量、强弱元素、元素精通和复杂 ICD。
- 新增草、风、岩等更多元素或更多反应。
- 枪械掉落、商店、随机词条、复杂改装和背包系统。
- 玩家近战、掩体系统、AI 队友位置指令和 AI 自动施放技能。
- 匹配、专用服务器、反作弊、跨平台、在线存档或正式多人发行。
- 三名首发角色、复杂关卡分支、长期局外成长和完整叙事内容。
