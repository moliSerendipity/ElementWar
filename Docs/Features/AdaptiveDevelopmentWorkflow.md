## 目标与范围

- 可观察目标：新对话使用 `继续下一阶段` 即可稳定定位同一个依赖合法的原子任务；不再重复长提示词，也不把所有功能强制塞进固定任务拓扑。
- 范围：根规则、ElementWar feature skill、工作流、设计导航、Feature Spec 模板、路线总览与四份路线细则。
- 非目标：运行时代码、测试代码、scene/prefab、ScriptableObject、Input Action、Project Settings、Git 提交或推送。
- 事实边界：设计文档维护目标行为，架构文档维护现状与边界，路线维护顺序和状态，Feature Spec 维护一次获批切片与证据。

## 风险与回滚

- 路线是当前规划，不证明远期功能已经实现；每个任务启动前仍需核对仓库漂移。
- 任务粒度过细会增加维护成本，因此按“一个可观察结果、一个主要风险边界、可独立验证”拆分，而不是按文件拆分。
- 回滚单位是本 Spec 及 `DOC-001` 涉及的规则与路线文档；不包含任何生产资产。
