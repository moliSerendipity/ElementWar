# 路线 03：敌人、Run 与 Boss

- 上级路线：[`DevelopmentRoadmap.md`](../DevelopmentRoadmap.md)
- 目标设计：[`Run.md`](../Design/Run.md)、[`Combat.md`](../Design/Combat.md)、[`Elements.md`](../Design/Elements.md)
- 当前架构：[`Architecture.md`](../Architecture.md)
- 维护日期：2026-08-11

敌人路线先用生产行为特征测试建立安全网，再决定局部加固或边界重构；不会预先承诺整套重写。Run 路线从唯一状态所有者开始，逐步接入波次、恢复、强化、失败与重开，最后用 Boss 和完整一次游玩收口。

> Planned/Ready 任务只表达目标、依赖和可观察结果；实现形状在任务成为 Next 时根据当前代码重新审计。旧实施提示由 Git 历史追溯，不保留在活动 Roadmap。

## M09 现有敌人链加固

### ENM-010 当前敌人生产行为特征测试与审计门
- 状态：Ready
- 依赖：`CMB-010`。
- 当前缺口：现有 EnemyBrain/StateMachine/Locomotion/Attack 已可运行，但缺少足够生产特征证据；直接重构无法区分历史行为、缺陷和设计变化。
- 可观察完成：当前敌人行为有可重复的特征测试和差异清单，后续每次修改能说明是兼容还是有意改变。
- 范围：只读审计与测试优先；发现生产缺陷若超出批准范围则另行授权。
- 解锁：`ENM-020`、`ENM-030`、`ENM-040`。

### ENM-020 敌人目标身份、威胁与锁定
- 状态：Planned
- 依赖：`ENM-010`、`PTY-010`。
- 当前缺口：敌人以 Transform 为主要目标，无法稳定表达双角色阵营、倒地过滤、威胁、锁定保持和切换后的重新选择。
- 可观察完成：双角色快速切换、倒地和复活时敌人始终有确定合法目标，不在两目标间每帧抖动。
- 范围：Enemy 决策与目标服务；非目标是复杂仇恨 UI 或网络同步。
- 解锁：`AI-020`、`ENM-050`～`ENM-070`。

### ENM-030 攻击生命周期与一次命中语义
- 状态：Planned
- 依赖：`ENM-010`、`CMB-010`。
- 当前缺口：攻击重叠查询可能按 Collider 处理，且帧跳跃、动画回调、禁用和目标离开可能导致漏击或重复提交。
- 可观察完成：一次挥击对同一角色最多一次伤害，两个不同合法目标可各一次；取消和帧跳不会重复或永久卡状态。
- 范围：EnemyAttack/状态机/动画适配；物理和计时风险高。
- 解锁：`ENM-050`～`ENM-070`、Boss 攻击切片。

### ENM-040 敌人死亡、禁用与池化重置
- 状态：Planned
- 依赖：`ENM-010`、`ENM-030`。
- 当前缺口：生命耗尽已统一，但目标、NavMesh、攻击回调、控制/附着、事件订阅和波次计数还没有完整 reuse 契约。
- 可观察完成：同一敌人实例反复租借与击杀，第二次行为与新实例一致，不产生幽灵攻击或重复死亡计数。
- 范围：Enemy 生命周期、对象池适配和事件；非目标是波次编排。
- 解锁：`RUN-030`、`PERF-010`。

### ENM-050 近战基础敌人与数据驱动调参
- 状态：Planned
- 依赖：`ENM-020`、`ENM-030`、`ENM-040`。
- 当前缺口：现有近战行为需收敛为主线可配置 prefab，攻击/移动/韧性/反馈资产需通过真实消费者校验。
- 可观察完成：近战敌人从生成到死亡可重复运行并被元素/控制正确影响。
- 解锁：`LVL-010`、`RUN-030`。

### ENM-060 远程敌人垂直切片
- 状态：Planned
- 依赖：`ENM-020`、`ENM-030`、`PRJ-010`。
- 当前缺口：没有使用统一投射物/攻击身份的远程敌人和射线/弹道预警。
- 可观察完成：远程敌人只攻击合法角色，投射物归因正确且有可读规避窗口。
- 解锁：多类型波次、Boss 远程攻击。

### ENM-070 重型精英、韧性与控制抵抗
- 状态：Planned
- 依赖：`ENM-020`、`ENM-030`、`CMB-030`、`ELM-080`。
- 当前缺口：没有验证普通敌人和 Boss 之间的控制抵抗、韧性窗口和重攻击威胁层级。
- 可观察完成：精英可被玩家策略性打出失衡，但不能被普通控制永久锁死。
- 解锁：`BOS-010`、精英波次。

### LVL-010 主线 Arena 灰盒与可验证生成点
- 状态：Planned
- 依赖：`LIC-010`、`ENM-050`。
- 当前缺口：Bootstrap 是当前主线入口，但首版战斗场地、NavMesh 边界、出生/复活/波次生成点和相机安全区尚未形成正式可验证布局。
- 可观察完成：两角色和代表敌人在场地中无明显卡住/出生重叠，重开可恢复同一基础布局。
- 范围：scene/prefab/NavMesh 序列化迁移，需引用检查和人工验收。非目标是最终美术装修。
- 解锁：`RUN-010`、`RUN-030`。

### LVL-020 研究设施主题、美术、照明与战斗可读性
- 状态：Planned
- 依赖：`LVL-010`、`LIC-010`、`BOS-030`。
- 当前缺口：灰盒能证明导航和生成，但尚未形成废弃元素武器研究设施主题、短入口教学、三方向来敌、远程高处、手雷弹跳表面和 Boss 安全空间的发布场景。
- 可观察完成：场景主题明确，普通波次与 Boss 威胁可读，导航/弹道/相机无因装饰产生的新阻断。
- 范围：scene、prefab、材质、灯光、音频序列化资产；需许可、GUID/引用、性能和人工验收。
- 解锁：`RUN-090`、`BUILD-010`。

### RUN-010 RunRuntime 与 StageRuntime 唯一状态机
- 状态：Planned
- 依赖：`ARC-010`、`LIFE-020`、`LVL-010`。
- 当前缺口：现有 Stage/Run 定义多为壳，没有一次游玩的权威状态、当前阶段、暂停/结算/失败和重开边界。
- 可观察完成：调试命令或最小场景可确定地推进合法状态，重复完成/失败事件不会二次转换。
- 范围：状态所有权与场景组合根；若实际改变长期所有权或组合根契约则升级 Full 并评估 ADR。非目标是实际波次、强化内容和结果 UI。
- 解锁：`RUN-020`、`RUN-050`、`HUD-030`。

### RUN-020 Stage/Wave 配置与运行时计划
- 状态：Planned
- 依赖：`RUN-010`、`ENM-050`。
- 当前缺口：现有 Stage 定义字段不足以驱动敌人组、延迟、上限、完成条件和可重复种子计划。
- 可观察完成：同一配置与种子生成同一波次计划，非法资产在进入 Play 前明确失败。
- 范围：Definition 与序列化配置，可能替换现有空壳；需要迁移计划/ADR。
- 解锁：`RUN-030`。

### RUN-030 波次生成、存活计数与结束门
- 状态：Planned
- 依赖：`RUN-020`、`ENM-040`、`LVL-010`。
- 当前缺口：没有基于权威 Spawned/Defeated 事实的波次计数、并发上限、生成失败处理和阶段结束伤害停机。
- 可观察完成：显示计数与真实存活敌人一致，最后敌人死亡只完成一次波次，失败/重开无幽灵敌人。
- 解锁：`RUN-035`、`UPG-020`、`PERF-010`。

### RUN-035 第一、第二波敌人编排与调试
- 状态：Planned
- 依赖：`RUN-030`、`ENM-050`、`ENM-060`、`ENM-070`。
- 当前缺口：运行时波次完成后仍需把设计中的教学组合与精英组合落成真实配置，并证明数量、方向、节奏和难度可读。
- 可观察完成：第一波教学移动/闪避/远程威胁，第二波突出精英优先级；相同种子可复现且不会因生成失败卡关。
- 范围：Stage/Wave 配置、生成点和反馈；非目标是第三波小怪，第三波只由 Boss 构成。
- 解锁：`RUN-040`、`PERF-010`。

### UPG-010 Typed Upgrade 定义、选择池与确定性抽取
- 状态：Planned
- 依赖：`MOD-010`、`RUN-010`。
- 当前缺口：没有可应用到角色/Party/武器/反应的类型安全强化定义、互斥/前置、权重和种子抽取。
- 可观察完成：相同种子和已选集合得到相同合法候选，非法组合在加载时拒绝。
- 范围：Definition/Gameplay 最小契约；只有形成长期跨模块公共契约时才升级 Full 并评估 ADR。非目标是九个内容一次完成。
- 解锁：`UPG-020`、`UPG-030`。

### RUN-040 波间恢复、复活窗口与选择流程
- 状态：Planned
- 依赖：`RUN-035`、`LIFE-030`、`UPG-010`。
- 当前缺口：波次结束后没有冻结战斗、恢复规则、倒地队友处理、强化候选和继续条件的一致阶段。
- 可观察完成：波间不能被迟到攻击伤害，恢复和复活各执行一次，重复确认不重复应用强化。
- 解锁：`UPG-020`、`RUN-050`。

### UPG-020 强化选择 UI 与原子应用
- 状态：Planned
- 依赖：`UPG-010`、`RUN-040`、`HUD-020`。
- 当前缺口：没有从权威候选快照渲染、确认、失败回滚和历史展示的 UI 流程。
- 可观察完成：一次波间只能应用一个候选，UI 文本与实际效果一致，失败时可安全重试。
- 解锁：`UPG-030`。

### UPG-030 九个强化的代表性分批实现
- 状态：Planned
- 依赖：`UPG-020`、`WPN-060`、`ELM-100`、`SKL-060`。
- 当前缺口：设计列出的九个强化没有生产实现、组合测试或版本裁剪顺序。
- 可观察完成：每个已声明强化都能从选择 UI 生效、在 Run 历史显示、重开清除；未完成项不出现在候选池。
- 解锁：完整内容版 Run；首版可在不破坏框架的前提下裁剪到前三个代表项。

### RUN-050 成功、失败与完整重开
- 状态：Planned
- 依赖：`RUN-010`、`LIFE-020`、`RUN-040`。
- 当前缺口：没有统一终局事实、输入/敌人停机、结果快照和跨系统完整 reset。
- 可观察完成：成功/失败只出现一次，连续重开多次与首次启动状态一致，无陈旧敌人、Buff 或 UI。
- 范围：跨系统 Run 收口；任务成为 Next 后按实际调用链选择必要验证，不预设无关防御或验证层级。
- 解锁：`BOS-010`、`RUN-090`。

### BOS-010 Boss 根、阶段与攻击调度
- 状态：Planned
- 依赖：`RUN-050`、`ENM-070`、`ELM-100`。
- 当前缺口：没有 Boss 身份、阶段状态、阶段配置、攻击调度、终局连接和完整 reset。
- 可观察完成：替身 Boss 可从进入到击败按阈值单向推进阶段，重复阈值/死亡事件不重入。
- 范围：Boss 公共骨架与替身，不实现全部攻击；状态所有权评估 ADR。
- 解锁：`BOS-020`～`BOS-050`、`HUD-030`。

### BOS-020 Phase 1 近战/远程攻击组
- 状态：Planned
- 依赖：`BOS-010`、`ENM-030`、`ENM-060`。
- 当前缺口：Boss 没有可读预警、冷却、互斥和安全取消的第一阶段攻击能力。
- 可观察完成：Phase 1 可独立游玩，攻击不会重叠成不可躲避的未批准组合。
- 解锁：`BOS-030`。

### BOS-030 Phase 2 场地威胁与组合攻击
- 状态：Planned
- 依赖：`BOS-020`、`PRJ-050`、`LVL-010`。
- 当前缺口：没有阶段转换后的持续区域、场地控制和复合攻击生命周期。
- 可观察完成：Phase 2 明显改变打法但仍有可读安全空间，重开不残留区域。
- 解锁：`BOS-040`、`BOS-050`。

### BOS-040 弱点、韧性与失衡窗口
- 状态：Planned
- 依赖：`BOS-010`、`CMB-030`、`BOS-030`。
- 当前缺口：伤害契约有 WeakPoint 倍率，但 Boss 没有弱点 Collider 到权威目标的映射、阶段启用规则和韧性失衡窗口。
- 可观察完成：打破韧性后弱点窗口按一次事务开始/结束，普通身体与弱点伤害可预测。
- 解锁：完整 Boss 战斗循环。

### BOS-050 Boss 元素反应与控制转换
- 状态：Planned
- 依赖：`BOS-010`、`ELM-100`、`BOS-040`。
- 当前缺口：六种反应在 Boss 上需要避免永久控制，同时仍要保留元素构筑价值。
- 可观察完成：六反应对 Boss 都有明确可见结果，Freeze 等控制不能锁死，Overload 等仍有策略收益。
- 解锁：`RUN-090`。

### HUD-030 波次、Boss 与结果 HUD
- 状态：Planned
- 依赖：`HUD-020`、`RUN-010`、`BOS-010`。
- 当前缺口：没有当前波次/存活数、Boss 生命/韧性/阶段、成功失败和重开的一致展示。
- 可观察完成：HUD 与实际状态一致且不参与完成判定，禁用/重开无重复订阅。
- 解锁：`RUN-090`。

### RUN-090 完整单次游玩验收
- 状态：Planned
- 依赖：`RUN-050`、`BOS-050`、`HUD-030`、`UPG-030`、`LVL-020`。
- 当前缺口：各切片尚未证明从启动、战斗、波间选择、Boss、成功/失败到重开的端到端闭环。
- 可观察完成：无开发者干预可完成一次 Run，并可重开第二次；所有 Must 行为可在证据中定位。
- 解锁：`REL-020`。
