# 战斗、角色与武器设计

- 状态：已确认设计检查点
- 维护日期：2026-08-07

本文是角色控制、AI 队友、武器弹药、技能、伤害、输入和战斗 HUD 的设计事实源。元素反应细节见 [`Elements.md`](Elements.md)，波次、敌人编排和肉鸽强化见 [`Run.md`](Run.md)。本文描述目标行为，不代表现有代码已经完成。

带有“初始调试值”的数字只用于建立首轮可玩版本，必须通过实际游玩调整。

## 队伍与角色状态

- 首版队伍由两名角色组成：火属性输出角色荧和冰属性辅助角色茜特菈莉；系统设计允许未来扩展到最多三名角色。
- 任意角色都可以使用任意枪械类型，不把武器类型绑定到角色职业。
- 每名角色分别持有生命值、终结技能量、武器运行时实例和弹药状态。
- 角色定义 ID 使用与第三方模型解耦的 `PyroAssault`和 `CryoSupport`，UI 显示名只使用“荧”和“茜特菈莉”。
- 玩家始终直接控制一名存活角色，另一名角色由 AI 控制。
- AI 队友会跟随、选择敌人并射击，但玩家不能命令其移动到指定位置，也不会自动释放技能；玩家必须先把该角色切换为主控，再使用 `E`或 `Q`。

## 角色切换

- `Tab` 在两名存活角色之间切换，初始共享冷却为 `1.5 秒`。
- 切换时两名角色交换世界位置，因此新主控角色出现在原玩家战斗位置，镜头继续停留在该战斗位置。
- 切换本身没有无敌时间，也不消耗专门资源；代价是冷却、动作中断和交换位置带来的受击风险。
- 切换会取消瞄准、普通换弹和尚未完成的元素特殊换弹。
- 已进入生效阶段的战技、终结技和闪避不能通过切换取消。
- 敌人已经进入出手阶段的攻击不会因切换而取消，仍可命中交换到该位置的新角色。
- 倒地角色不能成为切换目标。

## 倒地、接管与复活

- 两名角色拥有独立生命值；生命归零后倒在当前位置，不能移动、射击或被切换为主控。
- 当前主控角色倒地时，如果仍有存活队友，镜头和控制权转移到该队友当前所在位置，不再交换两名角色的位置。
- 存活主控角色进入倒地角色 `2` 米范围并按住 `F`持续 `2.5` 秒，可以消耗一个团队共享复活道具复活该队友；不能对自己使用。
- 复活交互期间不能移动、射击、换枪、切人或闪避，但可以转动镜头；松开按键、离开范围或受到伤害会取消并清空进度。
- 复活道具只在交互完整结束时扣除，中断不会消耗。
- 复活后恢复当前最大生命值的 `40%`，并获得 `1` 秒伤害免疫；当前最大生命值包含“强化装甲”等已生效修饰。
- 终结技能量和技能冷却在倒地与复活后保持原状态。
- AI 不会自动使用复活道具。
- 所有角色倒地时本局失败。
- 每局初始复活道具数量、波次间使用时机和重置规则见 [`Run.md`](Run.md)。

## AI 队友规则

- AI 队友可以被敌人选为攻击目标。
- 当前主控角色拥有更高基础威胁；距离和近期伤害共同影响目标选择。
- 敌人锁定目标后保持一个最短时长，攻击进入出手阶段后不重新选目标；倒地角色从候选目标中移除。
- Boss 比普通敌人更偏向当前主控角色，但仍可在规则允许时攻击 AI 队友。
- AI 控制期间承受的所有敌方伤害统一降低 `50%`（初始调试值），不按近战、远程、爆炸或环境来源分支。
- 同一角色被玩家控制时恢复正常承伤。
- AI 固有减伤与霜甲等其他减伤采用乘法组合。例如 `50%` 与 `25%` 减伤同时存在时，最终承受 `37.5%`伤害。
- AI 普通射击不消耗玩家保存的弹药，不附着元素，也不产生终结技能量；仍表现射击间隔和换弹动作。
- 玩家已经主动释放的持续技能在切换后继续生效，并不视为 AI 自动施法。

## 输入方案

首版正式支持键盘和鼠标。

| 行为 | 输入 |
|---|---|
| 移动 / 视角 | `WASD` / 鼠标 |
| 开火 / 瞄准 | 鼠标左键 / 右键 |
| 冲刺 / 跳跃 | `Left Shift` / `Space` |
| 闪避 | `Left Ctrl` |
| 普通换弹 | `R` |
| 切换枪械 | 鼠标滚轮 |
| 切换元素弹药 | `T` |
| 战技 / 终结技 | `E` / `Q` |
| 切换角色 | `Tab` |
| 投掷手雷 | 按住 `G`瞄准，松开投掷 |
| 互动 / 复活 | 按住 `F` |
| 暂停 | `Esc` |

- 首版不使用背包操作；现有 Input Actions 中的旧数字键技能、`F1`–`F4`队友切换、自由观察和背包 Action 在迁移时先检查引用，再决定保留或移除。
- 首版不承诺手柄操作，后续适配时不得改变已有键鼠行为。

## 移动与闪避

- 地面移动强调快速响应，减少明显的起步和停止延迟。
- 瞄准时降低移动速度，但不锁定方向。
- 冲刺会退出瞄准并停止射击；首版不设置体力条。
- 跳跃主要用于地形通过，空中控制较弱，避免连续跳跃成为主要规避手段。
- 闪避沿当前移动方向执行；没有方向输入时向后闪避。
- 闪避初始总时长约 `0.5 秒`，其中约 `0.2 秒`为无敌阶段，初始冷却约 `1.2 秒`。
- 无敌阶段不区分伤害类型；持续伤害区域会在无敌结束后的后续伤害判定继续生效。
- 闪避可以取消瞄准、射击和换弹，但不能取消已经进入生效阶段的技能。

## 武器与投掷物

- 首版使用固定配装，不实现枪械获取和改装；定义、运行时实例、配装提供者和数值修饰应保持可扩展，以便以后增加获得方式和改装系统。
- 首版每名角色的固定配装都包含一把步枪和一把榴弹枪；两名角色各自持有自己的武器实例和弹药状态，不共享唯一枪械对象。
- 步枪使用 Hitscan，支持火和雷元素弹药；腰射存在散布，瞄准射击更准确。
- 步枪后坐力以可学习的竖向上抬为主，只保留少量横向偏移，不使用强随机晃动。
- 榴弹枪使用真实弹道投射物，命中敌人或环境后爆炸，不发生弹跳，支持水和冰元素弹药。
- 榴弹直接命中获得额外伤害，范围伤害随距离衰减；榴弹的直接命中和范围伤害均不计算弱点倍率。
- 手雷会与环境发生弹跳；按住 `G`显示预测轨迹，松开后投掷，引信从脱手时开始，首版不能提前捏雷计时，也不附带元素。
- 榴弹枪和手雷复用通用投射物与范围伤害能力；元素应用是独立可选配置，首版只由榴弹枪启用。
- 队友之间没有友军伤害。由玩家输入发射或投掷的爆炸物只可能伤害来源角色，不伤害另一名队友；AI 自主发射的爆炸物不产生自身伤害。
- 爆炸物生成时固定来源角色以及由玩家还是 AI 发起；之后切人不会转移自身伤害归属。
- 最大自身伤害按 `爆炸基础伤害 × 基础距离衰减 × 25%`计算，使用爆炸配置的原始伤害和原始半径，不受攻击增益、元素反应或“爆破改良”影响；计算后仍可由霜甲等防御效果减免，并且可以使角色倒地。
- 首版不实现玩家近战和掩体系统。

## 弹药与元素特殊换弹

- 弹药状态按“角色 + 武器 + 元素”分别维护，每种元素有独立的弹匣内数量和备用弹药池。
- 不追踪每一个实体弹匣，也不保存半满弹匣对象。
- `R`执行当前元素的普通换弹；`T`在该武器允许的两种元素间循环并播放特殊换弹。
- 特殊换弹完整结束后，旧元素弹匣中的剩余子弹全部退回旧元素备用池，再从新元素备用池装填新弹匣。
- 特殊换弹被闪避、换枪或切人取消时，元素和弹药状态都保持原状。
- 换枪会中断普通换弹，不保存换弹进度。
- 元素切换不损失弹药，其成本只有动作时间和战斗暴露。
- 榴弹枪的弹匣和备用弹药容量明显低于步枪，具体容量在武器调试阶段确定。
- 每波之间的补给规则见 [`Run.md`](Run.md)。

## 命中、弱点与反馈

- 首版不加入随机暴击率和暴击伤害属性。
- 普通敌人可以配置明确弱点，弱点命中使用确定性倍率；Boss 弱点设计以 [`Run.md`](Run.md) 为准。
- 首版只有步枪命中和直接命中的非范围技能可以命中 Boss 弱点；榴弹枪、手雷及其他范围伤害不能命中 Boss 弱点。
- Boss 弱点开放时使用明显发光和独立音效，命中后使用现有弱点准星反馈；不增加部位破坏系统。
- 普通命中、弱点命中、元素反应和击杀使用不同的准星反馈与音效。
- 步枪连续命中的伤害数字在短时间内合并；爆炸、弱点和元素反应伤害单独强调。
- 步枪不开明显命中停顿，保证连续射击；重型爆炸、Boss 韧性击破和终结技可以使用很短的停顿与镜头震动。
- 镜头震动可以在设置中降低或关闭。
- 首版敌人的伤害形式只包含直接伤害和爆炸伤害；敌人不是元素来源，具体边界见 [`Elements.md`](Elements.md)。

## 终结技能量通则

- 两名角色分别拥有 `100`点终结技能量。
- 战技至少命中一名敌人时获得 `25`点，每次施放最多获得一次；未命中不获得能量。
- 普通射击、击杀、AI 射击和终结技本身不产生能量。
- 能量在切人、波次结束、倒地和复活后保留，新一局开始时清空。
- 技能冷却在角色由 AI 控制或倒地时继续计算。

## 角色与技能表现

- 荧以橙红色、尖锐线条、热浪和加速脉冲表现火属性输出定位。
- 茜特菈莉以青白色为主并保留紫色点缀，使用六边形或环形结构表现冰属性支援；霜冻领域边缘和霜甲轮廓必须清晰可读。
- 终结技只使用短促激活动作、音效和轻微镜头反馈，不播放长时间角色特写，不中断紧凑战斗节奏。

## 荧（火属性输出）

### 战技：点火协议

- 向准星位置发射一次火属性攻击，造成中等伤害并附着火元素。
- 无论是否命中，获得约 `6 秒`武器强化：射速提高约 `15%`，换弹速度提高约 `20%`。
- 强化期间，武器命中每隔约 `1.5 秒`可以额外附着一次火元素。
- 当前弹药是其他元素时可以由此触发反应；当前弹药已经是火时只刷新附着。
- 初始冷却约 `10 秒`；只有技能攻击命中时才按通则获得能量。

### 终结技：热能超频

- 激活时在角色周围产生一次火焰冲击，造成伤害并附着火元素。
- 随后进入约 `10 秒`强化状态：武器伤害提高约 `25%`、射速提高约 `20%`、换弹速度提高约 `30%`，并明显降低后坐力。
- 武器额外火附着间隔缩短到约 `0.75 秒`，但不提供无限弹药。
- 与战技强化同时存在时采用终结技的较强参数，不重复叠加同类数值。
- 切换为 AI 后持续时间照常流逝；AI 可以保留伤害、射速等原始数值强化，但仍不能通过普通射击附着火元素。

## 茜特菈莉（冰属性辅助）

### 战技：寒霜压制

- 在准星指向且处于允许距离内的地面位置产生范围冰爆。
- 造成较低至中等伤害并附着冰元素。
- 普通敌人受到约 `30%`减速，持续约 `4 秒`。
- 对 Boss 的减速效果降低，但造成额外韧性伤害。
- 初始冷却约 `12 秒`；至少命中一名敌人时按通则获得一次能量。

### 终结技：霜冻领域

- 在准星指向的位置生成固定区域，持续约 `10 秒`；切人或施法者倒地后仍持续到正常结束。
- 区域每秒造成一次较低冰属性伤害，但约每 `2 秒`才附着一次冰元素。
- 区域内的存活角色获得“霜甲”，承受伤害降低约 `25%`；离开区域后保留约 `2 秒`。
- 首版不增加独立护盾生命值和护盾条。
- 技能减速与反应减速的叠加规则见 [`Elements.md`](Elements.md)。

## 战斗 HUD

- 左下：两名角色头像、本名、元素图标、生命值、倒地状态、当前主控标记和团队共享复活道具数量。
- 右下：当前枪械、弹匣/备弹、当前元素图标、可切换元素图标和手雷数量。
- 技能区域：战技冷却和终结技能量。
- 顶部：当前波次和剩余敌人数；Boss 战显示 Boss 生命和阶段信息。
- 敌人附近：生命值和当前元素附着图标；Boss 额外显示韧性信息。
- 准星附近：命中、弱点、击杀和反应反馈。
- 元素只使用固定颜色和独立图标识别，不显示“火、水、雷、冰”等文字；不能只依赖颜色。
- 元素反应名称可以在触发时短暂出现一次，不持续占用界面。
- 已获得的肉鸽强化在战斗中最多显示两个小图标，完整说明放在暂停界面。

## 实现边界

- 配置定义、角色/武器运行时状态、伤害事实和表现层继续遵守 [`../Architecture.md`](../Architecture.md) 的唯一所有者与依赖方向。
- 现有输入资源可能仍包含旧 Action；实现时必须检查读取链和序列化引用，不能仅依据本设计直接删除。
- 本文不批准修改旧 Lua 元素系统、旧场景或当前敌人实现；对应迁移或重写必须建立独立 Feature Spec。
