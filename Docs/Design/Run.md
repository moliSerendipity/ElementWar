# 局内流程、敌人与肉鸽强化

- 状态：已确认设计检查点
- 维护日期：2026-08-07

本文是场景结构、三波流程、敌人编排、Boss、波次补给、失败条件和肉鸽强化的设计事实源。角色、伤害和威胁规则见 [`Combat.md`](Combat.md)，Boss 的元素特殊处理见 [`Elements.md`](Elements.md)。本文描述目标行为，不代表现有场景和敌人代码已经达到该状态。

## 单局结构

1. 玩家从短入口/教学区域进入主竞技场。
2. 第一波教学近战与远程敌人组合。
3. 波次结束后暂停战斗并进行第一次三选一。
4. 第二波混合普通敌人与重型精英。
5. 波次结束后进行第二次三选一。
6. 第三波进入两阶段 Boss 战。
7. 击败 Boss 后本局成功；全员倒地则失败并从第一波以新随机种子重新开始。

每局初始拥有 `1` 个团队共享复活道具，不通过掉落或波次奖励补充；开始新一局时重置为 `1` 个。具体复活行为见 [`Combat.md`](Combat.md)。

首版没有局外成长、长期货币、商店或关卡分支。

## 场景与叙事

- 主题为废弃的元素武器研究设施或测试场。
- 使用一个短入口/教学区域和一个主要竞技场，三波战斗复用同一竞技场。
- 竞技场中心保持较开阔的 Boss 战区域，外围设置侧路、阻挡物和少量适合远程敌人的高处。
- 墙面、斜坡和局部结构应支持手雷产生可预测且有价值的弹跳。
- 敌人主要从三个方向进入，避免完全包围时缺乏可读性。
- 不实现贴靠掩体机制；场景障碍只服务视线、走位、弹道和敌人编排。
- 强化选择在当前场景中完成，不进入独立商店或基地。
- 叙事只用一句话说明玩家进入设施并完成战斗试验；具体文案尚未确定，不制作 NPC、对话或过场。

## 敌人编排

| 类型 | 首版职责 |
|---|---|
| 近战追击者 | 迫使玩家移动和闪避，教学近距离威胁 |
| 远程射手 | 从中远距离施压，利用场地高低差和视线 |
| 重型精英 | 更高生存与韧性，提供第二波重点目标 |
| 两阶段 Boss | 综合考察射击、闪避、切人、技能和元素反应 |

- 第一波只组合近战追击者与远程射手，并逐步增加同时施压数量。
- 第二波混合两类普通敌人与一名重型精英。
- 第三波只聚焦 Boss，不增加召唤小怪系统。
- 敌人的具体威胁选择、锁定和出手后不换目标规则见 [`Combat.md`](Combat.md)。

## Boss 设计边界

- 第一阶段使用横扫/扇形攻击、直线重击和远程投射物，要求玩家识别方向和时机。
- 第二阶段提高节奏，并加入地面或区域持续威胁。
- Boss 不使用召唤、传送、独立护盾阶段、部位破坏或大型剧情演出。
- Boss 正常参与元素反应，没有元素免疫；冻结、超载等控制转换见 [`Elements.md`](Elements.md)。
- Boss 弱点平时关闭；每个阶段至少有一种指定重招在后摇期间开放弱点，第一阶段持续 `3` 秒，第二阶段持续 `2` 秒。
- Boss 韧性击破时开放弱点 `4` 秒；与招式后摇窗口重叠时取较晚的结束时间，不叠加多个窗口。
- 开放期间的弱点伤害倍率为 `1.50`；第二阶段只缩短招式后摇窗口，不提高倍率。
- 可命中弱点的攻击类型和表现反馈见 [`Combat.md`](Combat.md)，反应对弱点倍率的继承规则见 [`Elements.md`](Elements.md)。

## 波次结束与资源恢复

波次清空后按以下顺序处理：

1. 停止生成敌人与伤害，进入三选一界面。
2. 玩家选择并立即应用一个强化。
3. 所有枪械和各元素备用弹药按照新容量补满。
4. 手雷补满。
5. 每名存活角色恢复其当前最大生命值的 `20%`，不超过生命上限；倒地角色不恢复生命。
6. 终结技能量保持不变。
7. 不补充共享复活道具，也不自动复活倒地角色。
8. 关闭选择界面；若存在倒地角色且仍有复活道具，继续保持敌人与伤害停止，让玩家完成复活交互或主动跳过。
9. 开始下一波倒计时。

首版战斗过程中不随机掉落弹药补给，枪械弹药只按上述波次间规则恢复。

## 肉鸽选择规则

- 第一波和第二波结束后各选择一次，一局最多获得两个强化。
- 强化池共九项，全部是唯一团队强化，不能重复获得或叠层。
- 强化分为武器、元素和战术三组，每次三选一分别从三组各提供一个尚未获得的选项。
- 选项由本局随机种子决定；同一随机种子可以复现选项，便于测试。
- 不设置稀有度、重抽、商店、货币、叠层或局外解锁。
- 选择期间战斗暂停；战斗 HUD 只显示已选强化的小图标，完整说明放在暂停界面。

## 武器强化

### 精密校准

- 所有枪械后坐力降低 `25%`。
- 腰射散布降低 `20%`。
- 弱点伤害提高 `30%`。

### 战术供弹

- 所有武器弹匣容量提高 `25%`，出现小数时向上取整。
- 普通换弹和元素特殊换弹速度提高 `20%`。
- 获得后按新容量在下一波开始前补满弹药。

### 爆破改良

- 榴弹枪和手雷的爆炸伤害提高 `20%`。
- 爆炸半径提高 `20%`。
- 不改变自身伤害计算采用的基础伤害和基础半径；具体公式见 [`Combat.md`](Combat.md#武器与投掷物)。

## 元素强化

### 反应增幅

- 获得独立的 `1.25` 反应增幅倍率，原始反应倍率和伤害系数保持不变。
- 该倍率作用于反应伤害、韧性伤害和可数值化的硬直/削韧强度，不改变半径、目标数、位移、减速、易伤或控制持续时间。
- 完整计算规则见 [`Elements.md`](Elements.md#反应增幅)。

### 附着稳定

- 敌人身上的元素附着持续时间提高 `40%`。
- 同元素再次附着仍只刷新持续时间，不叠加层数。

### 快速转化

- 元素特殊换弹时间缩短 `35%`。
- 成功切换元素后，第一发命中必定附着新元素，不受该武器应用间隔限制。
- 第一发未命中时效果保留到命中或再次切换元素为止。

## 战术强化

### 技能回路

- 两名角色的战技冷却缩短 `20%`。
- 战技命中获得的终结技能量由 `25`提高到 `35`，三次成功命中即可充满终结技。

### 协同换位

- 完成角色切换后，新主控角色获得约 `6 秒`强化：武器伤害和战技伤害各提高 `20%`。
- 效果有 `10 秒`内部冷却，避免通过无意义频繁切换维持增益。
- 不改变角色切换的受击风险和敌人已提交攻击。

### 强化装甲

- 两名角色最大生命值提高 `25%`。
- 获得时按照最大生命值比例同步提高当前生命值。
- 不额外提供伤害减免。

## 强化与 AI

- 团队属性强化作用于两名角色，但不改变 AI 普通射击“不消耗实际弹药、不附着元素、不产生能量”的基础规则。
- 反应强化可以作用于玩家已经释放、切人后仍存在的持续技能。
- 协同换位只强化新主控角色，不强化被切换为 AI 的角色。
- 所有百分比均为首轮调试值，不是最终平衡承诺。

## 现有敌人实现的处理原则

- 当前敌人攻击范围、招式选择和代码质量存在用户已观察到的问题，但尚未完成足以证明必须重写的审计。
- 到敌人实现阶段，先复现漏洞、梳理调用链并建立特征测试，再比较局部修复与重写成本。
- 在完成该判断前，不修改、扩展或清理现有敌人系统，也不把“计划重写”写成既定结论。
